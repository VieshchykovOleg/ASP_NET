# Портал для опитувань
**Лабораторні роботи №1–7 | .NET 8**

## Загальний опис
Протягом курсу лабораторних робіт було розроблено повнофункціональну інформаційну систему **"Портал для опитувань"** на базі платформи **.NET 8**.  
Проект пройшов еволюцію від простого консольного додатку до складної розподіленої системи з:
-  Веб-інтерфейсом (ASP.NET Core MVC)
-  API (RESTful Web API + Swagger)
-  Клієнтським SPA-додатком (Blazor WebAssembly)
-  Підтримкою реального часу (SignalR)

---

## 🛠️ Етапи розробки та ключові досягнення

### 1️⃣ Налаштування середовища та базова архітектура *(Лаб. 1–2)*
- Створено проект на базі **ASP.NET Core MVC**
- Налаштовано `global.json` для фіксації версії SDK
- Інтегровано **Entity Framework Core (EF Core)** з SQL Server
- Реалізовано підхід **Code First** (моделі + міграції)
- Впроваджено патерн **Repository** з DI
- Створено механізм **SeedData** для початкового наповнення БД

---

### 2️⃣ Інтерфейс користувача та навігація *(Лаб. 2–3)*
- Головна сторінка зі списком опитувань
- Підключено **Bootstrap** через LibMan
- Реалізовано **пагінацію** (ViewModels: `PagingInfo`)
- Система **фільтрації опитувань** за категоріями
- Використано **View Components** для сайдбару
- Застосовано **Partial Views** для карток опитувань
- Реалізовано роботу з **Session** (кошик незавершених опитувань)

---

### 3️⃣ Розширення моделі даних та CRUD *(Лаб. 4–5)*
- Додано сутність **Question** (зв’язок "один-до-багатьох")
- Повноцінна **Адмін-панель** (`AdminController`) з CRUD
- Форми створення/редагування опитувань з **Tag Helpers**
- Серверна валідація через **DataAnnotations**

---

### 4️⃣ Безпека: автентифікація та авторизація *(Лаб. 5)*
- Інтегровано **ASP.NET Core Identity**
- Окремий контекст БД: `AppIdentityDbContext`
- Система ролей: **Admin** та **User**
- Контролер `AccountController` (реєстрація, вхід, вихід)
- Захист адмін-панелі через `[Authorize(Roles = "Admin")]`

---

### 5️⃣ Сервіс-орієнтована архітектура та Web API *(Лаб. 6, частина 1)*
- Винесено **Data Layer** та моделі в окремі бібліотеки
- Створено проект **SurveyPortal.Api**
- RESTful контролер `SurveysApiController` (JSON)
- Документація API через **Swagger UI**
- JWT-автентифікація (**Bearer Tokens**)

---

### 6️⃣ Клієнтський SPA-додаток *(Лаб. 6, частина 2)*
- Розроблено SPA на **Blazor WebAssembly**
- Взаємодія з API через **HttpClient**
- Відображення даних з сервера на клієнті
- Автентифікація на клієнті:
    - Форма входу
    - Збереження JWT у **LocalStorage**
    - Використання `AuthenticationStateProvider`

---

### 7️⃣ Реальний час з SignalR *(Лаб. 7)*
- Інтегровано **SignalR** для двостороннього зв’язку
- Створено хаб `SurveyHub`
- Механізм сповіщень: автоматичне оновлення даних при редагуванні
- JavaScript-клієнт для динамічного оновлення DOM без перезавантаження

---

## Підсумок
В результаті виконання лабораторних робіт було створено сучасну, масштабовану систему, що складається з:
- Серверної частини (**MVC + Web API**)
- Бази даних (**SQL Server + EF Core**)
- Захищеної панелі адміністратора (**Identity + Roles**)
- Інтерактивного клієнтського інтерфейсу (**Blazor + SignalR**)

Проект демонструє використання передових технологій стеку **.NET 8** та принципів сучасної архітектури.
